# Security policy

`tcp-sansio` parses packets that may come from untrusted networks, so
security reports are taken seriously.

## Supported versions

Only the latest release receives security fixes while the project is in the
`0.x` series.

## Reporting a vulnerability

Please do not open a public issue. Report the problem privately through
[GitHub's vulnerability reporting](https://github.com/AngeloHH/tcp-sansio/security/advisories/new)
and include the affected version, a description of the impact and, if
possible, the packets or code that reproduce it.

You can expect an initial answer within a week. Once a fix is released, the
advisory will be published with credit to the reporter unless anonymity is
requested.
